# 1С СервисПро — Landing Page

Ультра-современный продающий лендинг для компании, предоставляющей услуги по доработке, обслуживанию конфигураций 1С и размещению инфраструктуры на внешних серверах.

## Структура проекта

```
SiteMy/
├── index.html          # Основной лендинг
├── admin.html          # Админ-панель (Kanban-доска)
├── styles.css          # Кастомные стили и анимации
├── script.js           # JavaScript (i18n, анимации, формы)
├── assets/
│   ├── images/         # Изображения
│   └── icons/          # Иконки
└── README.md
```

## Технологии

- **HTML5** — семантическая разметка
- **Tailwind CSS** (CDN) — утилитарный CSS-фреймворк
- **Vanilla JavaScript** — без зависимостей
- **Inter** — шрифт через Google Fonts

## Запуск

Откройте `index.html` в браузере или используйте локальный сервер:

```bash
# Python
python3 -m http.server 8000

# Node.js
npx serve .

# PHP
php -S localhost:8000
```

## Функционал

### Лендинг (index.html)
- Hero-секция с анимированным дашбордом
- Блок ценностного предложения с иконками
- Сетка услуг (6 карточек)
- Таймлайн «Как мы работаем»
- Блок преимуществ
- Тарифы (3 карточки)
- Карусель отзывов с таймером и свайпом
- Форма обратной связи с валидацией
- Модальное окно авторизации (вход/регистрация)
- Онлайн-чат виджет
- Мультиязычность (RU/EN)
- Адаптивная верстка (mobile-first)
- Анимации при скролле
- Фиксированная шапка

### Админ-панель (admin.html)
- Kanban-доска с drag-and-drop
- 4 статуса: Новые → В работе → Ожидание клиента → Выполнено
- Создание новых заявок
- Чат внутри заявки
- Статистика по заявкам

## Кастомизация

### Цвета
Измените цвета в `tailwind.config` внутри HTML-файлов:
```javascript
colors: {
    'brand-red': '#E31E24',
    'brand-orange': '#F5A623',
    'brand-dark': '#1A1A2E',
    'brand-gray': '#2D2D44',
}
```

### Переводы
Добавьте новые языки в объект `translations` в `script.js`.

### Контакты
Замените placeholder-данные (телефон, email, адрес) на реальные.
